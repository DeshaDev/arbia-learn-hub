# الحروف العربية — Арабские буквы

Исходный интерактивный проект для русскоязычных детей, начинающих изучать арабский алфавит. Версия создана на основе предоставленного HTML-файла: сохранены оригинальные данные букв, обучающие тексты, SVG-иллюстрации, анимации, обведение букв и три игры. Код разнесён по файлам для дальнейшего развития.

## Что входит в проект

- 28 букв с арабскими названиями, подсказками о форме и точках, примерами слов и русскими пояснениями.
- Пошаговое знакомство с буквой и озвучивание средствами браузера.
- Обведение буквы с визуальной обратной связью.
- Три исходные игры: поймай букву сачком, отправь письмо и отнеси букву домой.
- Звёзды, последовательное открытие букв и локальное сохранение прогресса.
- Оригинальные SVG-иллюстрации и зайчик-помощник в том же стиле.
- Адаптивное оформление: исходный игровой опыт сохранён, стартовый экран и типографика улучшены.

## Файлы

- `index.html` — исходная структура страницы.
- `styles.css` — исходные стили с адаптивными улучшениями.
- `app.js` — оригинальные данные букв, анимации, упражнения и игровые режимы.
- `assets/mascot.svg` — персонаж, извлечённый из оригинальных иллюстраций.
- `tests/data-check.mjs` — проверка сохранности данных и функций проекта.

## Запуск локально

Откройте `index.html` в браузере или выполните:

```bash
python -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## GitHub Pages

Ветка `gh-pages` содержит статическую версию сайта в корне. Для GitHub Pages укажите **Deploy from a branch → gh-pages → /(root)** в настройках репозитория. После обновления исходной папки скопируйте изменённые файлы в корень `gh-pages`.

## Примечание

Голос зависит от доступных голосовых движков браузера. Исходные названия букв, транскрипции и слова оставлены из предоставленного файла; их корректность следует отдельно проверить с преподавателем арабского языка.
