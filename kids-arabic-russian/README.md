# Али и арабский мир 🇷🇺 ↔ 🇸🇦

Игровой веб-проект для русскоязычных детей, начинающих учить арабский язык. Работает как статический сайт: HTML, CSS и JavaScript, без сборщика и внешних зависимостей. Али — собственный векторный персонаж в `assets/mascot.svg`.

## Возможности

- Все 28 букв арабского алфавита с примером слова, русским значением и приблизительной транслитерацией.
- Озвучивание букв и слов через SpeechSynthesis в браузере.
- Практика написания мышью, пером или пальцем.
- Словарные карточки с поиском и фильтрами.
- Викторина с обратной связью и звёздами.
- Локальное сохранение выученных букв и результатов в браузере.
- Управление озвучиванием арабских букв и слов.
- Адаптивная вёрстка для телефонов и компьютеров.

## Локальный запуск

Можно открыть `index.html` напрямую либо запустить HTTP-сервер:

```bash
python -m http.server 8000
```

Перейдите на `http://localhost:8000`.

## Примечания

Русские обозначения некоторых арабских звуков условные: у нескольких звуков нет точного аналога в русском языке. Доступность произношения зависит от голосов браузера. Учебные результаты не отправляются на сервер и сохраняются только в localStorage браузера.

## Публикация на GitHub Pages

Для этого проекта подготовлен отдельный статический branch `gh-pages` с готовыми файлами сайта в корне. Так публикация не зависит от Actions token, который не смог создать Pages site через API.

1. В настройках репозитория откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **gh-pages** и папку **/(root)**, затем нажмите **Save**.
4. Через несколько минут откройте ссылку, которую покажет GitHub Pages в настройках.

Если изменяете исходники в `kids-arabic-russian/`, скопируйте обновлённые `index.html`, `styles.css`, `app.js` и `assets/mascot.svg` в корень ветки `gh-pages`. Автоматические проверки находятся в `.github/workflows/validate-kids-arabic-app.yml`.
