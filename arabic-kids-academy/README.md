# Али и арабский мир — интерактивная академия арабского для детей

Полноценная статическая веб-платформа для детей, изучающих арабский язык с русским интерфейсом. Проект вдохновлён предоставленным референсом в подходе к обучению через героя, сцену, букву, озвучивание и игру; структура продукта, учебная навигация, прогресс и геймификация построены как отдельный расширяемый проект.

## Что реализовано

- Первый экран-приключение с анимированным зайчиком Али и движущимися облаками.
- Пошаговый путь обучения: 28 букв, словарь, фразы, аудирование, письмо и игровые задания.
- Урок буквы: знакомство с формой и точками, разговор Али, озвучивание, вопрос на распознавание, рисование буквы и награда за завершение.
- Несколько игровых режимов: выбери нужную букву, доставь письмо и найди пары.
- Словарь с категориями и поиском; аудио произношение через браузер.
- Счёт XP, серия учебных дней, ежедневные миссии и значки достижений.
- Хранение прогресса в localStorage без серверной регистрации.
- Адаптивная вёрстка, клавиатурные состояния фокуса и поддержка reduced motion.
- Авторский зайчик-вектор в assets/rabbit.svg.

## Структура

- index.html — оболочка и навигация.
- styles.css — дизайн-система и адаптивные состояния.
- app.js — учебные данные, маршрутизация, локальный прогресс и игровые механики.
- assets/rabbit.svg — векторная маскот-персонаж.

## Запуск

Откройте index.html в браузере или запустите локальный сервер:

    python -m http.server 8000

Затем откройте http://localhost:8000.

## Технические ограничения

Проект не требует backend. Прогресс хранится локально в браузере и не синхронизируется между устройствами. Произношение зависит от доступных речевых голосов браузера; русская транскрипция служит подсказкой для новичка, а не фонетической транскрипцией. Перед учебным использованием названия, огласовки и переводы рекомендуется проверить с преподавателем арабского языка.
